Add-ons Importer

Pick an exported file from Add-ons Exporter. HTML, JSON, CSV, and TXT formats are all supported, and so is the .zip the Exporter makes when you tick several. If a .zip holds files with different add-ons, a picker lets you choose which set to import (or all of them). The Add-ons you don't have yet are pre-selected, while your installed ones are shown too if you want to check them.

Note: Firefox doesn't allow any extension, including this one, to automatically install other add-ons. It can only open each add-on's page as a tab for you. You'll still need to click Add to Firefox yourself on each one.
